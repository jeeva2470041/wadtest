1. Variables & Data Types let, const, var, primitives

JavaScript has 3 variable keywords (let, const, var) and primitive vs reference types.

// 1. Variable Declarations
const appName = "StudentApp"; // Block-scoped, cannot be reassigned
let score = 95;               // Block-scoped, can be reassigned
var legacy = "old style";     // Function-scoped (hoisted, avoid in modern JS)

// 2. Data Types
let str = "Hello World";      // String
let num = 42;                 // Number (integers & floats are both 'number')
let bool = true;              // Boolean
let unassigned;               // undefined (variable declared with no value)
let empty = null;             // null (intentional absence of any object value)
let sym = Symbol("id");       // Symbol (unique identifier)
let big = 9007199254740991n;  // BigInt

2. Functions (Declarations, Expressions & Arrow Functions) () => {}, closures, default params

Functions are first-class citizens in JavaScript. They can be stored in variables and passed as arguments.

// 1. Function Declaration (Hoisted)
function add(a, b = 0) {
  return a + b;
}

// 2. Function Expression
const multiply = function(a, b) {
  return a * b;
};

// 3. Arrow Function (ES6 - concise syntax, lexical 'this')
const square = (n) => n * n;

// 4. Closure Example (Inner function retains access to outer variables)
function createCounter() {
  let count = 0;
  return () => ++count;
}
const counter = createCounter();

3. Arrays & Functional Methods map, filter, reduce, forEach, find

Modern JavaScript relies heavily on declarative, non-mutating array iteration methods.

const students = [
  { id: 1, name: "Priya", score: 92 },
  { id: 2, name: "Arun",  score: 68 },
  { id: 3, name: "Kiran", score: 85 },
  { id: 4, name: "Divya", score: 55 }
];

// map(): Transform each element into a new array
const names = students.map(s => s.name);

// filter(): Filter elements based on condition
const passed = students.filter(s => s.score >= 70);

// reduce(): Accumulate values into a single result
const totalScore = students.reduce((acc, curr) => acc + curr.score, 0);

// find(): Returns the first matching element
const topper = students.find(s => s.score > 90);

4. Objects, Destructuring, Spread & Optional Chaining {...spread}, destructuring, ?.

ES6+ introduced powerful syntax improvements for inspecting and manipulating objects.

const student = {
  id: 101,
  name: "Priya",
  course: "Web App Dev",
  contact: { email: "priya@example.com" }
};

// 1. Destructuring with Default Values
const { name, course, role = "Student" } = student;

// 2. Spread Operator (...) for copying or merging
const updatedStudent = { ...student, grade: "A+" };

// 3. Optional Chaining (?.) and Nullish Coalescing (??)
const phone = student.contact?.phone ?? "No phone provided";

// 4. Template Literals (String interpolation)
const summary = `${name} is enrolled in ${course}. Contact: ${phone}`;

5. DOM Manipulation (Document Object Model) querySelector, createElement, classList

JavaScript dynamically alters page content, structure, and styles in real-time.

// 1. Selecting Elements
const element = document.getElementById("myId");
const cards = document.querySelectorAll(".card"); // Returns NodeList

// 2. Modifying Content & Attributes
element.textContent = "New Plain Text";
element.innerHTML = "<strong>HTML Content</strong>";
element.setAttribute("data-role", "admin");

// 3. Modifying Classes (Recommended over inline styles)
element.classList.add("active");
element.classList.remove("hidden");
element.classList.toggle("highlight");

// 4. Creating & Appending Elements
const newDiv = document.createElement("div");
newDiv.textContent = "I was dynamically created!";
document.body.appendChild(newDiv);

6. Event Handling & Listeners addEventListener, click, input, keydown

Events allow JavaScript to respond to user interactions (clicks, keyboard input, mouse motion).

// Modern event listener syntax
const btn = document.querySelector("#myBtn");

btn.addEventListener("click", (event) => {
  console.log("Button clicked!", event.target);
  event.stopPropagation(); // Prevents bubbling
});

// Real-time input listening
const input = document.querySelector("#search");
input.addEventListener("input", (e) => {
  console.log("Current value:", e.target.value);
});

8. Asynchronous JavaScript, Promises & Fetch API async / await, Promises, fetch()

Handle non-blocking tasks like fetching data from REST APIs (e.g. Spring Boot).

// 1. Promise Definition
const delay = (ms) => new Promise(resolve => setTimeout(resolve, ms));

// 2. Async/Await with Try...Catch
async function fetchStudentData() {
  try {
    const response = await fetch("http://localhost:8081/api/students");
    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }
    const data = await response.json();
    console.log("Students loaded:", data);
  } catch (error) {
    console.error("Fetch failed:", error.message);
  }
}

9. LocalStorage, SessionStorage & JSON localStorage.setItem, JSON.stringify

Save data across browser reloads without a backend database.

// 1. Convert JavaScript Object to JSON String
const profile = { username: "priya_wad", theme: "dark" };
const jsonString = JSON.stringify(profile);

// 2. Save to localStorage
localStorage.setItem("userProfile", jsonString);

// 3. Retrieve and Parse JSON
const savedData = localStorage.getItem("userProfile");
const user = JSON.parse(savedData); // Converts back to JS Object

10. ES6 Classes & Object-Oriented Programming (OOP) class, constructor, extends, super

Modern syntactic sugar over prototypal inheritance.

// Base Class
class Person {
  constructor(name) {
    this.name = name;
  }
  introduce() {
    return `Hello, my name is ${this.name}.`;
  }
}

// Subclass (Inheritance)
class Student extends Person {
  constructor(name, rollNo) {
    super(name); // Calls parent constructor
    this.rollNo = rollNo;
  }
  introduce() {
    return `${super.introduce()} I am a student with Roll No: ${this.rollNo}.`;
  }
}
