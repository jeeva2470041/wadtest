2. Text Formatting & Inline Semantics <strong>, <em>, <mark>, <code>...

Inline tags format text with visual style and semantic meaning.

Strong text: <strong> indicates important text (bold).

Bold text: <b> simply bolds text without extra importance.

Emphasized text: <em> adds verbal emphasis (italic).

Italic text: <i> displays text in italics.

Marked text: <mark> highlights reference points.

Small text: <small> represents fine print or side-comments.

Deleted text: <del> shows removed text (strikethrough).

Inserted text: <ins> shows added text (underlined).

Subscript & Superscript: H2O (<sub>) and E = mc2 (<sup>).

Short inline quote: Practice makes progress (<q>).

Abbreviation: HTML (<abbr> with tooltip).

8. HTML5 Semantic Layout Elements <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>

Semantic tags give meaning to webpage structure for search engines (SEO) and screen readers.

Article Component (<article>)

Published on October 14, 2026 (<time>)

Aside Note (<aside>)

The aside element represents a portion of a document whose content is only indirectly related to the document's main content (like sidebars, tips, or callout boxes).

9. Interactive & Modern Intermediate Tags <details>, <summary>, <dialog>, <iframe>

Modern HTML elements providing native interactive capabilities without external plugins.

Collapsible Disclosure (<details> & <summary>)

What is HTML5?

HTML5 is the latest major revision of the HTML standard, introducing semantic elements, canvas drawing, video, audio, and client-side storage APIs.

Why use semantic tags?

Semantic tags improve accessibility (a11y) for screen readers, boost Search Engine Optimization (SEO), and make the source code much easier to maintain.
