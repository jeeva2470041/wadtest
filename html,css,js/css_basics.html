1. CSS Syntax & 3 Ways to Apply CSS Inline, Internal, External

CSS (Cascading Style Sheets) styles and formats HTML elements. It can be applied in 3 ways:

1. Inline CSS: Written directly in HTML tag using style="...".

This paragraph is styled via inline CSS style attribute!

2. Internal CSS: Inside <style> in the <head> of this HTML file.

3. External CSS: Linked via <link rel="stylesheet" href="style.css"> (Recommended for scalability).

/* CSS Rule Anatomy */
selector {
  property: value;      /* Declaration */
  color: #2563eb;       /* Property: color, Value: #2563eb */
  font-size: 16px;      /* Property: font-size, Value: 16px */
}

3. The CSS Box Model Margin, Border, Padding, Content

Every HTML element is a rectangular box consisting of: Content, Padding, Border, and Margin.

MARGIN (Space outside the border)
BORDER (Visible boundary)
PADDING (Space inside border around content)
CONTENT (Width × Height of actual text/image)

box-sizing: content-box vs border-box

With border-box, padding and border are included in width calculation (standard modern practice).

content-box (default) Width 100% + 20px padding + 10px border = expands outside!
border-box (recommended) Width 100% includes padding & border perfectly!

6. Display Property (Block, Inline, Inline-Block, None) block, inline, inline-block, none

Determines how elements render in document flow.

display: block — Takes full available line width and forces a line break.
Another block element below it.
inline 1 inline 2 (Inline flows with text; ignores top/bottom margin & width/height).
inline-block A
inline-block B
(Flows inline BUT honors width, height, padding & margin).
